## Public use conditions found

- **Intesis:** HMS's [Media Centre](https://www.hms-networks.com/about-hms/media-center) says its press images, including logos, are free to use when mentioning HMS. Its linked [public library](https://portal.cloudinary.com/hms-networks/public_images) states that its images remain HMS property and may be used in connection with HMS products and solutions. The included original blue mark retains the complete “by HMS Networks” attribution. It appears only as identification of the already-listed Intesis equipment, with no approval or partnership claim. The public-library permission is more specific than the general [HMS website terms](https://www.hms-networks.com/terms-of-use), which otherwise reserve commercial copying of website graphics.
- **ABB:** its published [branding tips](https://library.e.abb.com/public/b3ad2c7bfec94c779bdc1c8f10819c05/ABB%20branding%20tips%202022.pdf) specify a red logo on white as the primary treatment and clear space based on logo height. The supplied PNG already includes generous transparent vertical margins. Preserve its colour and add surrounding space. This guidance is not evidence that Thalir is an ABB authorised distributor.
- **All included manufacturers:** ownership remains with the respective manufacturer. No open-source licence, endorsement, dealer authorisation or partnership is claimed. No affirmative general commercial licence was found for the other included header marks during this bounded source check. Future brand-specific instructions or supplied agreements should be recorded here.

## Technical treatment and verification

- Assets are hosted locally. No browser request goes to a manufacturer, CDN, logo API or font provider.
- SVG files retain the original path data, styling, colours and viewBox. Each was parsed as XML and checked for scripts, event handlers, foreign objects, embedded images, animation, imports and external href/CSS URL references; none were present.
- Original vector files, SATION PNG and ABB PNG are byte-for-byte unchanged. Zennio is proportionally reduced from 2560 × 1162 to 640 × 290; Intesis from 3204 × 674 to 480 × 101. Both preserve the complete mark and original clear-space canvas and use lossless WebP encoding. EAE and Blumotix use lossless WebP at original pixel dimensions. No mark was traced, cropped, recoloured or generated.
- All twelve marks were visually inspected on white; the rejected white-on-transparent header variants were not used.
- The twelve assets total **77,992 bytes before HTTP compression**. Serve below-the-fold marks with `loading="lazy"` and `decoding="async"`. Reuse the same URLs across pages for browser caching.
- Width and height in `BRAND_ASSETS` encode each file's aspect ratio. Decimal SVG viewBox dimensions are scaled to integers for valid HTML image attributes. CSS controls display size with `object-fit: contain`.
- ABB and Zennio have substantial built-in clear space; avoid a uniform small `max-height` that makes their actual marks tiny. EAE and Klipsch use taller original formats. Give these marks appropriate individual display sizing within a consistent shared grid; preserve proportions.
